# Задачи ЛР2 — Диаграмма компонентов (Level 3)

Требования методички (п. 1.2): декомпозиция ключевого контейнера бизнес-логики
(бэкенда) на внутренние компоненты; ≥ 4 взаимосвязанных компонентов в едином
адресном пространстве; явное разделение ответственности (многослойная
архитектура); текстовое обоснование и спецификация внутренних интерфейсов;
отчёт в ЭОС.

Выполнение: контейнер `api_backend` декомпозирован на 6 компонентов
(api_router, forecast_comp, analytics_comp, report_comp, data_repo, db_repo),
три слоя, 13 связей с протоколами (Python Call / HTTPS/JSON / SQL/TCP 5432 /
файловый I/O). Спецификация интерфейсов — реальный REST API проекта
(/api/population, /api/forecast, /api/report и др.) и программные контракты
сервисов/репозиториев.

Инструменты: PlantUML + C4-PlantUML (C4_Component.puml), только Rel(), без skinparam.
Артефакты: diagrams/components_l3.puml + png, отчет_ЛР2.md/docx/pdf.
