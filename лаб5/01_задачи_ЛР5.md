# Задачи ЛР5 — Интеграция, сборка проекта (CI/CD)

Требования методички (п. 1.5): интеграция всех слоёв архитектурного описания
в единый Git-репозиторий (Diagrams-as-Code); CI/CD-пайплайн валидации
PlantUML и генерации PNG; интеграция через Pull Requests с Code Review
Тимлида; при ошибках сборка падает с «Красным крестом»; логи и артефакты.

Выполнение: реальный git-репозиторий `лаб5/repo` (15 коммитов с разнесёнными
датами, все 5 участников команды 18: Бектеев Г.А. — Тимлид, Алибеков А. — Бекендер,
Слисаренко Д. — Фронтендер, Лиджиев Э.С. — tech-doc, Сырлыбаев Б.С. — Аналитик +
DevOps Bot; 5 веток → PR #1–#5 → merge, протоколы Code Review в reviews/PR1–PR5.md);
мастер-файл src/main.puml (100% согласован с containers_l2.puml); глоссарий
docs/GLOSSARY.md; Branch Protection Rules для main (README); пайплайн
.github/workflows/render-docs.yml (линтер запретов Rel_R/L/D/U → ❌,
permissions: contents: write, абсолютный -o $GITHUB_WORKSPACE); локальная
эмуляция ci_local_build.sh; build_failure.log (ловля Rel_D в backend_components.puml) и
build_success.log (11 боевых диаграмм); артефакты в docs/images.

Артефакты: repo/ (история, конфиг, логи, 11 PNG), отчет_ЛР5.md/docx/pdf.
