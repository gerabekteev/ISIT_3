# Задачи ЛР3 — Диаграмма кода (Level 4) и прототип на Python

Требования методички (п. 1.3): UML Class Diagram для выбранного компонента;
обязательный паттерн «Стратегия» для динамической подмены алгоритмов;
чистый ООП-код на Python со строгой аннотацией типов; соответствие SOLID;
отчёт в ЭОС.

Выполнение: компонент `forecast_comp` (см. ЛР2) детализирован до 8 классов
(ForecastStrategy ABC; HoltWintersStrategy, ArimaStrategy,
CohortComponentStrategy; ForecastContext; контракты данных TimeSeries,
ForecastResult, ForecastMetrics). Прототип — пакет `src/forecasting/`
(8 модулей, чистая стандартная библиотека), демо `src/demo.py` подменяет
стратегии в runtime; вывод демо — demo_output.txt (MAPE 0.18% / 0.05% / 0.53%).

Инструменты: PlantUML (UML class diagram), Python 3.14, java/Graphviz для рендера.
Артефакты: diagrams/class_diagram.puml + png, src/, demo_output.txt, отчет_ЛР3.md/docx/pdf.
