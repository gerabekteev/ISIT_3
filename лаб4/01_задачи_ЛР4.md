# Задачи ЛР4 — Ландшафт L0, динамическая диаграмма, развертывание

Требования методички (п. 1.4): ландшафт Level 0 (встраивание в корпоративную
среду, ≥ 2 смежных систем + 1 финансовая, протоколы gRPC/HTTPS/OAuth2);
динамическая диаграмма сквозного процесса с нумерацией вызовов; диаграмма
развертывания (узлы, Docker-контейнеры, порты/TLS, репликация, балансировка).

Выполнение: `landscape_l0.puml` (3 пользовательские роли + Enterprise_Boundary
«Ведомственная ИТ-инфраструктура»: DemoScope + ЕСИА(IAM) + CRM; внешние:
Росстат, ЕМИСС, Gemini, биллинг облака — счета/оплата; gRPC/HTTP2, OAuth 2.0,
HTTPS/REST); `dynamic_process.puml` (сценарий «Построение прогноза», шаги 1–12,
вход через api_router, кэш проверяется до расчёта, доступ к озеру данных строго
через data_repo — слои Backend API соблюдены); `deployment.puml` (Yandex Cloud:
Nginx 443/TLS → FastAPI в Docker (порт 8000) → PostgreSQL 5432 Master-Replica
(WAL) + чтение аналитических выборок с реплики, озеро данных по NFS (порт 2049),
Docker Host, Cron с загрузкой из Росстата/ЕМИСС/Google Drive, проверка токенов
ЕСИА; ID контейнеров — строго по глоссарию ЛР1).

Артефакты: diagrams/*.puml + png (3 диаграммы), отчет_ЛР4.md/docx/pdf.
