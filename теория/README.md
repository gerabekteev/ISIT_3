## ⚠️ Расхождение нумерации лабораторных работ

В материалах два разных варианта нумерации ЛР:

| Методичка (в2, 2026) — **основной документ** | Слайды лекции/семинара |
|---|---|
| **ЛР1** = Диаграмма системного контекста (L1) **+ Диаграмма контейнеров (L2)** | ЛР1 = контекст, ЛР2 = контейнеры (отдельно) |
| **ЛР2** = Диаграмма компонентов (L3) | ЛР3 = компоненты |
| **ЛР3** = Диаграмма кода (L4) + Python | ЛР4 = код |
| **ЛР4** = Ландшафт (L0) + Динамика + Развертывание | ЛР5 = ландшафт + динамика |
| **ЛР5** = Интеграция, Git, CI/CD | «Интеграция C4» — вне нумерации |

Сами требования к диаграммам при этом совпадают. **Ориентироваться следует на методичку** — она новее и содержит точные формулировки требований; конспекты слайдов полезны командными (интеграционными) требованиями, которых в методичке в развёрнутом виде нет.

## Как пользоваться

1. Нужно вспомнить теорию C4 (уровни, абстракции, правила оформления) → открыть конспект лекции.
2. Нужно понять, что сдавать и когда, требования к ЛР и интеграции в команде → открыть конспект семинара 1.
3. Нужно точно знать требования конкретной ЛР → открыть методичку (или её текст) + файлы в `../лаб1/`.
